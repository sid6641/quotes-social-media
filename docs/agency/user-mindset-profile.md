# User Mindset Profile — 2026-07-08

Captured from Lavish brainstorming session.

## Core Identity

- **Brand Builder** — building brands for ~20 different products
- Running ~10 Instagram accounts as a portfolio
- Currently in **Curator** mode, evolving toward **Automator → Growth Hacker → Brand Builder**

## Evolution Path

```
Curator → Automator → Growth Hacker → Brand Builder
(now)      (next)      (soon)          (always)
```

## Feature Requests (Priority Order)

1. **🔴 Instagram API Setup** — "We have to get over this." Must unblock auto-publishing.
2. **🔴 Analytics Dashboard** — Track what works / what doesn't per account. Engagement metrics, post performance.
3. **🟡 Generate 5 Image Variants** — Select any image, click "generate 5 variants", Gemini creates slight variations preserving the original quote/template.
4. **🟢 Multi-Account Management Platform** — Full dashboard to manage 10 accounts with independent schedules, sandboxes, auth.
5. **🔵 Auto-publish (Set & Forget)** — When quality is high enough, trust AI to post directly.

## Success Metrics

- Lots of followers per account
- High engagement
- Quality content that performs well

## Key Insights

- Willing to auto-publish if production quality is good enough ("why not?")
- Analytics should feed back into the system to improve image generation end-to-end
- Each product/brand needs its own "personality" — visual style, voice, tone
- Instagram API restriction is the #1 blocker for the whole vision
