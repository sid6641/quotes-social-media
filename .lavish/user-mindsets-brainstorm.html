🧠 Who Uses This Tool?

A brainstorming session on the mindsets, motivations, and mental models of people who run automated quote-image Instagram accounts.

Curator Automator Growth Hacker Brand Builder Side Hustler

🎭 The Five Mindsets

These aren't different people — they're different modes any user switches between depending on the day, the account, or the goal. Annotate which ones resonate and which ones the tool serves well (or poorly).

🔍

The Curator

Quality-first High touch

"Every single post represents my brand. I'd rather post nothing than post something mediocre."

🧠 Mental Model

  • • Sees each image as a reflection of taste
  • • Reviews every single image before it goes out
  • • Tweaks captions manually — AI is a draft, not final
  • • Curates which quotes make the cut

✅ Tool Serves Well

  • • Review UI — approve/reject per image
  • • 5 caption options to pick from
  • • Custom caption editing
  • • Export Calendar — manual control over what posts

⚠️ Missing / Could Improve

  • • No way to re-generate a single image
  • • Can't preview all 5 captions side-by-side
  • • No "reject and retry" for bad generations
  • • No notes/annotation on rejected images
Satisfaction: 75%
⚙️

The Automator

Efficiency-first Low touch

"I want to wake up to fresh content every morning without touching a thing."

🧠 Mental Model

  • • Trusts the AI to produce good enough content
  • • Wants a fully unattended pipeline
  • • Measures success by "did it post today?" not perfection
  • • Runs multiple accounts at scale

✅ Tool Serves Well

  • • Autopilot — generate on cron schedule
  • • Multi-account — all accounts in one command
  • • CLI pipeable — can chain with other tools
  • • Cron setup — `--setup-cron`

⚠️ Missing / Could Improve

  • • No auto-approve (by design — user wanted manual)
  • • No way to auto-post when IG API unblocks
  • • No notifications — "generation complete" ping
  • • No dashboard showing "health" of all accounts
Satisfaction: 60%
📈

The Growth Hacker

Data-driven Experimental

"Which caption style gets more engagement? What time should I post? Let's A/B test everything."

🧠 Mental Model

  • • Obsessed with engagement metrics
  • • Tests caption tones against each other
  • • Schedules posts at peak times per timezone
  • • Iterates on hashtag sets constantly

✅ Tool Serves Well

  • • 5 caption options per image — natural A/B testing
  • • Hashtag bank — reusable sets, fast switching
  • • Per-account schedule with timezone
  • • Caption learning store — tracks popular picks

⚠️ Missing / Could Improve

  • • No engagement tracking — what performed well?
  • • Can't link caption choice → post performance
  • • No hashtag analytics — which tags drive reach?
  • • No posting time optimization based on history
  • • Caption learning is manual (user picks) not automatic
Satisfaction: 45%
🎨

The Brand Builder

Aesthetic-driven Long-term

"All my accounts need to feel cohesive. Each one has its own voice, its own look, its own audience."

🧠 Mental Model

  • • Each account has a distinct personality
  • • Visual consistency matters — templates, colors, mood
  • • Voice/tone is tailored per account (motivation vs philosophy)
  • • Thinks in "content pillars" and "brand guidelines"

✅ Tool Serves Well

  • • Per-account themes — filter quotes by vibe
  • • Per-account config — name, description, identity
  • • Isolated directories — no cross-contamination
  • • Per-account publish schedule

⚠️ Missing / Could Improve

  • • Per-account prompt templates (one prompt fits all)
  • • Per-account visual style guide in prompts
  • • No "brand voice" setting for captions
  • • Can't preview an account's feed as a grid
Satisfaction: 55%
💰

The Side Hustler

Monetization-first ROI-focused

"These accounts aren't just for fun — they're assets. I need to know which ones earn and which ones cost me."

🧠 Mental Model

  • • Runs 5-20+ accounts as a portfolio
  • • Monetizes via shoutouts, affiliate links, digital products
  • • Wants minimum time per account — scale is the game
  • • Measures: followers gained, engagement rate, revenue

✅ Tool Serves Well

  • • Multi-account — unlimited accounts
  • • Autopilot — generate for all in one command
  • • CLI + JSON — can script, automate, pipe
  • • Low overhead — text files, no database

⚠️ Missing / Could Improve

  • • No analytics — zero insight into account performance
  • • No monetization tracking
  • • No "account health" dashboard
  • • Manual posting still required (IG API restricted)
  • • No content calendar view across ALL accounts
Satisfaction: 50%

🔥 Universal Pain Points

🚫 Instagram API Blocked

Every mindset is blocked by Meta's anti-spam restriction. No auto-publishing possible. Export calendar is the workaround, but it's manual.

Affects: All 5

📊 Zero Analytics

No feedback loop. Users don't know which posts perform well. The Growth Hacker and Side Hustler are flying blind.

Affects: Growth Hacker, Side Hustler

🎨 One Prompt Fits All

All accounts use the same image generation prompt template. The Brand Builder can't differentiate visual styles per account.

Affects: Brand Builder, Curator

🔋 No "Set & Forget"

Autopilot generates, but someone still needs to review, export, and post manually. True automation is blocked by the API restriction.

Affects: Automator, Side Hustler

❓ Open Questions for You

1️⃣ Which mindset are you in right now?

Curator, Automator, or a mix? The tool's design decisions depend on this.

2️⃣ How many accounts do you want to run?

3? 10? 50? The scaling strategy changes a lot after ~5 accounts.

3️⃣ What does "success" look like for each account?

Followers? Engagement? Revenue? Creative satisfaction?

4️⃣ Would you ever auto-publish without reviewing?

If the AI gets good enough, would you trust it to post directly? Or is review always non-negotiable?

5️⃣ What's your biggest bottleneck right now?

Generating enough images? Reviewing them? Posting? Sourcing quotes? Getting followers?
