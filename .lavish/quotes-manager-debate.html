Phase 2 — Quotes Manager

Scraper vs Generator

How should we auto-populate the quote pool for each Instagram account?

⚠️

Current State — Manual Only

Quotes must be entered by hand via npm run cli quotes add or imported from .txt files. No accounts have automated quote replenishment. Once the 10 seed quotes are used or cooldowned, generation stops.

The Decision

Which approach should we build to keep the quote pool healthy without manual effort?

Option A

🕸️ Quotes Scraper

Crawl quote websites & extract

How it works

Firecrawl scrapes pages from sites like BrainyQuote or Goodreads. Extract quote text + author, dedup against pool, import as "imported" source.

firecrawl_scrape("brainyquote.com/topic/inspirational")
  → [{ text, author }, ...]
  → importQuotesToPool(...)
  → 50 new quotes available

Pros

  • + Real quotes from real people — authentic, proven
  • + Author attribution built-in
  • + Zero API cost (Firecrawl has free tier)
  • + Broad variety — scrape by topic, author, mood

Cons

  • − Legal gray area — scraping may violate ToS
  • − Site structure changes break the scraper
  • − Quotes are not unique — other pages use them too
  • − Need to handle duplicates, rate limits, captchas
  • − No control over tone matching the account's theme
Dependencies: Firecrawl MCP (already available)
Option B

🤖 AI Quotes Generator

Use Gemini to generate original quotes

How it works

Gemini prompt generates N original quotes with optional author attribution. Each quote is unique. Can be themed per account. Stored as "ai-generated" source in the pool.

generateContent("Write 10 inspirational quotes...")
  → [{ text: "Fall seven times...", author: "AI" }, ...]
  → importQuotesToPool(...)
  → 10 new quotes, fully unique

Pros

  • + 100% unique content — no copyright concerns
  • + Themed per account: "motivation", "humor", "minimalist"
  • + Full control over tone, length, style
  • + No external service dependency (uses existing Gemini key)
  • + Can generate in any language

Cons

  • − Gemini API cost per generation (~$0.01 per 50)
  • − AI quotes may feel generic or inauthentic
  • − No real author attribution (less relatable)
  • − Quality varies — needs prompt engineering + curation
Dependencies: Gemini API (already configured)

Two Generator Paths — "Plan A vs Plan B"

Captain wants to compare both approaches before committing:

Plan A

Text → Pool → Image Pipeline

1. Gemini generates quote text (10 at a time)
2. Quotes stored in pool (source: ai-generated)
3. Existing pipeline picks quotes + templates
4. Gemini generates composite image
  • + Reuses existing generation pipeline
  • + Quotes are reusable — multiple images per quote
  • + Template backgrounds give visual consistency
Plan B

Direct — Instagram-Ready Image

Gemini generates a full 1080×1080px image
with quote text embedded, styled,
colored, and composed — ready to post.
  • + Single step — no template needed
  • + Diverse visual styles per image
  • + No background image library needed
  • − No quote pool — one-off generation
  • − Less brand consistency across posts
  • − Gemini cost per image ~$0.02 vs per batch ~$0.01
Proposed Hybrid Architecture

Best of both: use the generator as the primary source for themed, unique quotes, and add a scraper fallback for occasional high-quality real quotes.

💡

Recommendation

Start with the Generator. It's simpler, fully controlled, themable per account, and has zero legal or maintenance risk. The Gemini API is already configured and paid for.

Add the scraper later (P2) as an occasional supplement — a single command to pull in real quotes when you want variety. The Firecrawl MCP is already available when needed.

Open Questions — Annotate Below
Q1

Should the generator produce quotes with fake authors ("—AI") or remain anonymous?

Impacts engagement: attributed quotes feel more authentic.

Q2

Should autofill run on a schedule (cron) or on-demand via CLI?

Cron = set-and-forget but more code. CLI = manual but simpler.

Q3

What theme categories should the generator support?

e.g., "motivation", "humor", "minimalist", "philosophy", "success" — should these map to account config?

Q4

How many new quotes per autofill run?

10? 25? 50? Must balance API cost vs pool availability.
