💻 2. CLI Commands — Complete Reference

All CLI commands support --json for pipeable JSON output. Logger writes to stderr — stdout stays clean for piping.

Entry point: npm run cli -- [command] [args] or npx tsx src/cli/index.ts [command] [args]

cmd generate — Create Quote Images

Generates Instagram-style quote images using Gemini AI. Each image is a 1080×1080px composited asset with a styled quote over a generated background.

# Generate 5 images for the default account
npm run cli -- generate --count 5
# Generate 10 images for a specific account (filtered by theme)
npm run cli -- generate --count 10 --account dailygrind
# Generate with a specific template, output JSON
npm run cli -- generate --count 3 --template minimal --json
FlagTypeDefaultDescription
--countnumber10Number of images to generate
--accountstring—Target account ID (scopes templates, themes, quotes)
--templatestring—Override template selection
--jsonflagfalseOutput results as JSON array
cmd list — Query Available Resources

Browse available quotes, templates, and prompts. Three subcommands that each support --json.

# List all quotes in the pool
npm run cli -- list quotes --json
# List available templates
npm run cli -- list templates
# List available prompt templates
npm run cli -- list prompts
cmd account — Multi-Account Management

Full CRUD for Instagram account sandboxes. Each account gets its own isolated directory with config, manifest, queue, and images.

# Create a new account
npm run cli -- account create "dailygrind" \
  --display-name "Daily Grind" \
  --themes motivation,success \
  --schedule 09:00
# List all accounts
npm run cli -- account list --json
# Get account details
npm run cli -- account get dailygrind --json
# Update account config
npm run cli -- account update dailygrind --display-name "Daily Grind 🔥"
# Delete an account
npm run cli -- account delete dailygrind
SubcommandDescription
createCreate new account sandbox
listList all configured accounts
getShow single account details
updateModify account config
deleteRemove account and all its data
Account config fields: id, displayName, themes (filter which quotes are available), schedule (publish time), igUserId, igAccessToken, cooldownDays, (default 30) createdAt, updatedAt
cmd quotes — Quote Pool Management

Manage the self-maintaining quote pool with lifecycle tracking (available → used → cooldown → recycle).

# List all quotes (with status, theme, use count)
npm run cli -- quotes list --json
# Add a quote manually
npm run cli -- quotes add --text "The best time was yesterday. The next best is now." --author "Unknown" --theme motivation
# Import quotes from a text file (auto-dedup)
npm run cli -- quotes import ./quotes/new-quotes.txt
# Show pool statistics
npm run cli -- quotes stats
# Force-expire cooldown for certain quotes
npm run cli -- quotes expire --theme motivation
SubcommandDescription
listList all quotes with status, theme, use count
addAdd a new quote
importBatch import from text file (dedup by content)
statsPool statistics (available/used/cooldown/retired)
expireForce-expire cooldown quotes by theme
cmd publish — Queue & Publishing

Manage the publish queue and trigger Instagram publishing. Supports dry-run, force-publish, and status checks.

# Show queue status (pending / published / failed)
npm run cli -- publish --status
# Publish all queued items (dry run first)
npm run cli -- publish --dry-run
# Force-publish (ignore schedule — publish everything now)
npm run cli -- publish --force
# Publish for a specific account
npm run cli -- publish --account dailygrind --status
FlagTypeDescription
--statusflagShow queue contents without publishing
--forceflagPublish all queued items immediately
--dry-runflagSimulate publishing (show what would happen)
--accountstringScope to specific account
cmd help — Built-in Documentation
npm run cli -- help

Prints usage information for all available commands.

Backward Compatible

🌐 3. API Endpoints — Complete Reference

All endpoints live under src/app/api/ (Next.js Route Handlers). The app runs on http://localhost:3000 by default.

Method Endpoint Module Description
POST /api/generate generate/route.ts Trigger AI image generation. Body: { count, account?, template? }
GET /api/status status/route.ts Get generation status for latest batch
GET /api/batch-status batch-status/route.ts Batch-level status with detailed image-by-image info
GET /api/images/[filename] images/[filename]/route.ts Serve generated images (static file serving)
GET /api/manifest manifest/route.ts Get batch manifest (all generated images metadata)
POST /api/caption caption/route.ts Generate 5 AI caption options for an image. Body: { quote, imagePath }
POST /api/caption caption/route.ts Record a caption pick. Body: { selectedOption, editedCaption? }
GET /api/hashtags hashtags/route.ts Get suggested hashtags bank
GET /api/queue queue/route.ts List all queued items (with status: pending/published/failed)
POST /api/queue queue/route.ts Add item to publish queue. Body: { batchId, imageId, account? }
DELETE /api/queue queue/route.ts Remove item from queue. Body: { batchId, imageId }
POST /api/publish publish/route.ts Trigger publishing. Body: { force?, dryRun?, account? }
POST /api/status status/route.ts Approve (auto-queues) or reject an image. Body: { batchId, imageId, action: "approve"|"reject" }
GET /api/accounts accounts/route.ts List all accounts
POST /api/accounts accounts/route.ts Create a new account. Body: account config
DELETE /api/accounts accounts/route.ts Delete an account. Body: { id }
GET /api/quotes quotes/route.ts List all quotes with status
POST /api/quotes quotes/route.ts Add a quote. Body: { text, author?, theme? }
DELETE /api/quotes quotes/route.ts Remove a quote. Body: { id }
GET /api/templates templates/route.ts List available image templates
💡

Pro Tip: Pipe with curl + jq

All API responses are JSON. Pipe through jq for filtering: curl -s http://localhost:3000/api/queue | jq '.entries[] | select(.status=="pending")'

1. Select Quote
Picks a random available quote from the pool. Filtered by account themes if scoped.
2. Mix Template
Selects a visual template and combines it with the quote text for the AI prompt.
3. Generate Image
Gemini AI (gemini-3.1-flash-image) creates a 1080×1080px image with styled quote + background.
4. Generate Captions
Sends the actual generated image to Gemini (gemini-2.5-flash-image) to produce 5 caption options that match the visual mood.
5. Review
Open the web UI → Review tab → see each image → read caption options → Approve (auto-queues) or Reject.
6. Publish Queue
Approved items sit in the queue, scheduled for PUBLISH_TIME (default 09:00).
7. Publish
CLI publish or API /api/publish sends to Instagram via Graph API. Shows as "published" in queue.

📜 6. Quote Pool System

The quote pool is a self-managing lifecycle system. Every quote moves through states:

%%{init: {'theme': 'base', 'themeVariables': { 'background': 'transparent', 'primaryColor': '#7c3aed', 'primaryTextColor': '#fff', 'lineColor': '#6b7280' }}}%% stateDiagram-v2 [*] --> Available: Seed / Import Available --> Used: Image generated Used --> Cooldown: 30d timer starts Cooldown --> Available: Timer expires Available --> Retired: Used 5+ times Retired --> [*]: Removed from pool note right of Available Filtered by account themes when --account is set end note
StateMeaningTransition
AvailableReady to be used for generation→ Used when picked
UsedQuote has been used recently→ Cooldown after generation
CooldownOn timeout (default 30 days)→ Available after expiry
RetiredUsed 5 times — permanently done→ Removed from pool
⚡ Each quote tracks per-account usage — same quote can be used on different accounts independently.

🤖 7. AI Caption Pipeline (v2)

🖼️ Image-Aware

Captions are generated by sending the actual generated image to Gemini, so captions match the visual mood, colors, and composition.

5️⃣ Five Options

Each image gets 5 distinct caption tones: warm · bold · story-driven · minimalist · philosophical.

📚 Self-Learning

Tracks which caption style users pick in output/caption-examples.json. Top 2 most-picked examples become few-shot prompts.

🛡️ Graceful Degradation

If caption generation fails, the image proceeds without captions — never blocks the pipeline.

📁

Learning Store

File: output/caption-examples.json — capped at 50 entries, sorted by pickCount (most popular first).

📋 8. Publish Queue System

🖥️ 9. Review UI — Browser Dashboard

The web UI at http://localhost:3000 is the main review surface. It has two tabs:

📸 Review Tab 📋 Publish Queue Tab

📸 Review Tab

  • ✅ Shows all generated images from latest batch
  • ✅ Each image card shows: preview, quote text, 5 caption options
  • ✅ Approve button → auto-adds to publish queue
  • ✅ Reject button → removes from queue + discards
  • ✅ Status badges: pending, approved, in queue, published
  • ✅ Account scoped if generated with --account

📋 Queue Tab

  • ✅ Shows all queued items with status badges
  • ✅ Each entry shows: image preview, quote, scheduled time
  • ✅ Remove button to dequeue
  • ✅ Publish Now button → triggers immediate publish
  • ✅ Dry-run mode available
  • ✅ Filterable by status (pending/published/failed)
⏺️ The UI auto-refreshes — no manual reload needed after approving/rejecting.

📊 10. Structured Logging (Pino)

All logging uses Pino — structured JSON logger. Key behaviors:

FeatureDetail
Output formatJSON by default — trivially queryable with jq and grep
Stdout disciplineLogger writes to stderr (fd 2) — stdout stays clean for pipeable CLI output
Pretty modeLOG_PRETTY=true for human-readable output
Log levelLOG_LEVEL=debug for verbosity
Per log linetimestamp, level, module, message + structured data
ReplacedAll console.log/console.error across CLI and lib files
# Watch generation logs in real-time
LOG_LEVEL=info LOG_PRETTY=true npm run cli -- generate --count 5
# Pipe JSON logs to jq for filtering
LOG_LEVEL=info npm run cli -- generate --count 3 --json 2>&1 | grep '"level":30' | jq '{msg, module}'

🚀 11. Quick Start Guide

From zero to published post in 7 steps:

1
Create an account
npm run cli -- account create "mybrand" --display-name "My Brand" --themes motivation,wisdom --schedule 09:00
2
Import quotes
npm run cli -- quotes import ./quotes/my-quotes.txt
3
Check the pool
npm run cli -- quotes stats
4
Generate images
npm run cli -- generate --count 10 --account mybrand
5
Review in browser
Start the dev server: npm run dev → open http://localhost:3000 → Review tab → Approve/Reject
6
Check the queue
npm run cli -- publish --account mybrand --status
7
Publish
npm run cli -- publish --account mybrand --force
🔁

Daily Workflow

Run step 4-7 daily. The quote pool auto-recycles (30-day cooldown). Import fresh quotes weekly.
