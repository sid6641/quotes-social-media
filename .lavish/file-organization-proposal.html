✅ Proposed — One folder per account

📂 output/
├── 📄 accounts.json ← master account list
├── 📂 dailygrind/ ← every account is a folder
│ ├── 📂 batches/ ← each generation run
│ │ ├── 📂 2026-07-08-001/
│ │ │ ├── 📄 01-great-work.png
│ │ │ ├── 📄 01-great-work.caption.txt
│ │ │ ├── 📄 02-difficulty.png
│ │ │ ├── 📄 02-difficulty.caption.txt
│ │ │ └── 📄 manifest.json
│ │ └── 📂 2026-07-08-002/ ← next run
│ │ ├── 📄 01-...png
│ │ └── 📄 01-....caption.txt
│ ├── 📂 calendar/ ← approved, ready to post
│ │ ├── 📄 2026-07-09.png
│ │ ├── 📄 2026-07-09.caption.txt
│ │ ├── 📄 2026-07-10.png
│ │ └── 📄 2026-07-10.caption.txt
│ ├── 📂 archive/ ← already posted
│ │ └── 📄 2026-07-09.png
│ └── 📄 queue.json ← publish schedule
├── 📂 deepthoughts/
│ ├── 📂 batches/
│ ├── 📂 calendar/
│ ├── 📂 archive/
│ └── 📄 queue.json
└── 📂 morningwisdom/
📂 ...

🤔 Why this works

👁️ Open folder → see accounts

No more digging through nested directories. Each account is a top-level folder inside output/.

📋 Batches by date

Every generation run is a dated batch folder. Open a batch → see all images with their captions side-by-side.

📅 Calendar = to-do list

The calendar/ folder is your posting queue. Each day you don't need to think — just open the day's folder and post.

📦 Archive = ledger

Published content moves to archive/. You can look back at any date and see exactly what posted.

🔍 Find by account + date

Looking for a specific post? output/dailygrind/batches/2026-07-08-001/ — it's always the same pattern.

🔄 CLI + UI match

The file structure mirrors how the tool works: generate → batch → approve → calendar → archive.
